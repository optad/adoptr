# adoptr

Adaptive optimal two-stage designs for clinical trials with one or two
arms. For details on the core theoretical background, see:

> Pilz M, Kunzmann K, Herrmann C, Rauch G, Kieser M. A variational
> approach to optimal two-stage designs. *Statistics in Medicine*.
> 2019;38(21):4159–4171. <https://doi.org/10.1002/sim.8291>

## Installation

Install the latest CRAN release via

``` r

install.packages("adoptr")
```

and the development version directly from [GitHub](https://github.com/)
with:

``` r

devtools::install_github("optad/adoptr")
```

## Documentation

The documentation is hosted at <https://optad.github.io/adoptr>.
